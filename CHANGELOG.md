# Changelog

Each release has an entry here, under a `## <version>` heading that matches
the version in `Cargo.toml` and the release tag. The release workflow
publishes the entry as the release notes and in `latest.json` (what Bridge's
update check shows), and refuses to release a version without one.

## 1.0.0

- Rebuilt from the ground up, with a new tray panel.
- The tray icon shows your mouse's battery.
- Bridge remembers your mice and finds them when they're plugged in.
- Low-battery and game-profile alerts on screen.
- Updates download and install from inside the app.
- Installers for Windows, macOS and Linux.
- Linux support, with a one-click fix for mouse permissions.
- macOS: the cursor no longer freezes while Bridge talks to a mouse.
